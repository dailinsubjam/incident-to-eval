# 案例、时间与证据

在确定题目目标、来源范围或准备抓取数据时使用。本页字段是语义要求，
可映射到现有框架，不要求创建同名字段或采用特定文件格式。

## 先核目标与来源

从原始告警、日志/指标、变更、复盘和领域解释恢复事件。保留来源定位符、版本、
读取状态、时间与支持/反证关系；转抄同一来源不是两份独立证据，工具列表不是实际调用记录。
后验根因和人工操作可帮助拟题，但不自动成为唯一答案或 Agent 当时可见的事实。

分清启动输入、可查询调查材料、私有关联：多条告警可以启动一次调查，也可以只有一条入口；
其余同窗记录通过接口发现。同窗、同规则或共同对象不自动证明同一事故或共同根因。
如果被测系统需要发现或聚合这些关系，不能提前把关联结果写进输入。

拟定检查点时核对：这一判断会让值班多知道什么，或改变什么行动？支持它的证据在本题
声明范围内是否可得？作者已有确认应沿用，新分歧才定向确认。检查点不由当前工具库存、
一次调用路径或现有 Agent 得分倒推。

## 时间合同

分别声明数据窗口、信息截止点、原生事件时间、首次可查询时间和本次捕获时间。
时间戳要有时区/偏移与区间边界；来源桶标签代表起点还是终点也需依据。
历史可见性与当前抓取时间不同，运行时长不会解锁更多历史信息。

按要回答的问题选择截止点：

- **在既定时刻能判断什么**：固定业务指定时刻，预期结论只使用当时可得证据。
  不能为得到完整根因而后移时刻。
- **已有诊断目标何时具备足够证据**：先核定目标和一组有效的支持证据，再取这些证据
  均已可通过声明接口获得的最早时刻。可用该组证据首次可得时间的最大值表示，
  不表示证明了所有可能调查路径的全局最早时刻。
- **事后回顾性重建**：历史数据可查但首次可见性无法证明时，明确该限制与可见材料，
  不与严格历史截止点题混为同一实验条件。

晚入库、晚发布的记录不因事件时间在窗口内就提前可见。完整统计桶跨过截止点时，
不能作为当时已知的完整统计值。当前拓扑、成员或配置也不能冒充事故版本。
只评诊断与建议时无需延长到事故结束；要判断已恢复时，另定恢复观测窗口及判据。

冻结窗口独立限制保存范围，并包括任务所需的故障前对照。各来源有不同窗口时逐项记录，
不把零散覆盖拼成连续覆盖。补采保留真实捕获时间和新版本；不倒填时钟或覆盖旧快照。

## 题目与评分参考的隔离

| 内容 | 放在哪里 |
|---|---|
| 真实启动输入、任务所需的既有背景与权限边界 | Agent 输入 |
| 希望 Agent 自己发现的异常、关系、正常对照与候选事件 | 可查询证据；固定输入题则按其约定交付 |
| 后验根因、人工解释、修复结果、检查点和答案标签 | 私有评分参考及来源账 |
| 截止点之后的信息 | 严格历史题的私有背景，不能用于给 Agent 提示或奖励猜中 |

题面、标题、文件名、对象名单、表别名、分区与工具说明也检查泄漏；
保留中性或来源原生语义。不要把事后确定的故障对象包装成原本可用的查询入口。
评分参考需要真实的访问隔离：Agent 若可读整个工作区，就把私有文件移出其可访问范围。

## 采集计划与完整性

按来源记录：用途、身份/版本、实际只读请求、窗口与时钟、对象和字段、原生粒度、
分页/排序/聚合合同、正常对照/干扰项、预估体积、脱敏、完整性、hash 和接入状态。
发现目录、schema、对象映射、代码/配置与历史路由也是可能的依赖，不只保存异常指标。

需新采集时先验证一个最小真实请求，再在授权范围内抓取；已有材料先核来源与覆盖。
优先保全易失的版本、成员和状态；
冻结发现数据后检查下游依赖。补数据导致被选中的对象或窗口变化时，重新对账后续请求，
不能把新选窗与旧明细拼在一起。独立核验声明内未被本次 Agent 使用的能力。

逐来源决定保存原生统计还是逐条诊断记录：

- 原生计数、分布与时间桶：保存单位、分母、维度、桶边界和原查询；不复制每条业务记录，
  也不从统计值生成伪日志。
- 需要请求关联、错误类型、先后顺序时：保存必要的逐条诊断字段和稳定关联，包含合理对照；
  不只按后验错误签名挑选记录。
- 业务 payload 与无关大字段：先源端投影，避免无必要地采出客户内容。自由文本仍需检查内嵌数据。

完整性只针对已声明的来源、对象、窗口、字段、粒度与查询能力。保存每页/分区的请求、
返回/保留行数、完成标志、缺口及响应 hash。达到 limit 且无完成证据不算全量；
无法可靠去重时保留并标记，不凭相同文本删除合法重复记录。零行必须有成功查询与完整覆盖依据。

成功分区保留，失败分区按原预算续采。跨批检查来源修订、身份映射、桶边界与重叠值；
有差异就保留版本，不挑更符合答案的一份覆盖原件。

## 存储与表示

可采用版本化对象存储、本地文件、数据库快照或固定调用记录；必须能够按版本定位相同内容。
平台留存延期适合补证，但可变平台视图不是不可变回归输入。固定调用记录不能宣称任意查询。

容量按所选表示的行数和字节估算，不按业务吞吐量机械放大。存储和模型上下文预算分别规划：
保留数据，用有界查询/分页读取；不要为上下文装不下静默删掉承诺的证据。
容量不足时说明分区、外置、缩窗或抽样的代价，在现有授权内推进；改变范围需明确并版本化。

无损压缩只改变存储编码。抽样、删除诊断字段、合并时间桶都是证据变更。
压缩对象与展开内容分别保留 hash、体积和行数，通过实际 reader 核对读取结果；
不把压缩体积当作内存需求或采集完整性的证明。
