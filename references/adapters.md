# 接入不同 Agent 与证据适配层

在实际运行前使用。下面规定可观察行为，不规定语言、框架、工具名称或类层次。
复用既有回放器、依赖注入、CLI 工具、HTTP/MCP 接口或文件读取器均可；
选择目标系统实际支持的方式，没有实现就明确说明，不给示例名字附会真实可用性。

## 三个接入点

| 接入点 | 应保存与验证的内容 |
|---|---|
| 输入绑定 | 实际启动入口、版本/配置、触发集合、身份和顺序、窗口/虚拟时间、转换规则、实际消费的输入 |
| 证据接口 | 声明的发现/查询能力如何映射到冻结数据，参数和返回语义、覆盖范围、缺失/错误及访问隔离 |
| 答卷选择 | 同一次运行的完成信号、最终产物标识、选取字段/消息/文件、解析规则及原始产物/评分输入 hash |

被测对象可以是完整服务、CLI Agent、库入口或隔离推理模块；按实际边界命名。
离线调用核心模块不等于已经验证告警入口、队列、存储或用户界面。
已有部署入口不是必要条件，但不得用一个临时替代 Agent 的分数证明原系统表现。

输入转换只能执行预声明的必要编码/字段映射，不添加后验发现。
一次输入多条告警时验证每条确实被消费；查询到其他告警不等于多入口能力已验收。

## 证据接口的三层核验

1. **数据层**：冻结对象存在、版本/hash/完整性及时间语义成立。
2. **接口层**：声明内的发现、过滤、排序、分页、关联或统计实际可执行，结果来自相同快照。
3. **受测系统层**：实际入口使用该接口，记录本次请求及进入系统/模型的结果。

同一份数据可有多个适配器。协议可以不同，但适配前后保留任务承诺的查询能力、
单位、身份关联、时间粒度和错误语义。只读取固定片段的回放器不能被描述成自由查询环境。
如果适配层改变了能力范围，把它作为实验环境变化；不能仅凭工具名字相同就认定条件相同。

自主调用工具与应用预采集后给模型分别记录。前者可评价选择来源和组织查询，
后者只能对实际覆盖的采集流程与证据解释作结论；不要要求框架为通过测试而伪造工具调用。
数据已接入且接口完备，但 Agent 没有调用，是能力表现，不是无效题。

## 查询与覆盖

保留原请求参数。对请求窗口与已保存覆盖取交集，同时返回实际覆盖、缺口、截断及粒度；
完全不相交时返回明确的无覆盖状态。不要静默缩小请求后声称完整。
原生统计桶不能任意切分、插值或由汇总重建逐条记录。查询不满足原生粒度时，说明不支持，
或按事先声明的合同返回带原始边界的完整桶，不能伪装成精确子窗值。

目标框架可以用状态码、异常或结构化元信息表达，但至少区分：

| 结果 | 含义 |
|---|---|
| 完整成功/成功零行 | 声明范围完整返回；零行有真实查询和覆盖依据 |
| 部分覆盖/截断 | 只返回一部分，并说明已知缺口 |
| 未采集/无覆盖 | 快照没有对应材料，不表示现场没有异常 |
| 不支持 | 参数组合或查询能力超出已实现合同 |
| 调用失败 | 权限、来源、解析或其他执行错误，保留分类 |
| 截止点不可见/超出范围 | 请求不满足时间或权限合同，不向调用者泄漏隐藏答案 |

回放期间阻止意外访问当前生产数据；缺数据时不能自动 fallback 到线上。
有意开展的 live 实验另立条件与报告。既定范围之外的新能力/数据以新版本补充。

## 正式答卷可以是什么

| 实际系统 | 答卷选择规则示例 |
|---|---|
| 聊天 Agent | 本次会话在约定完成事件后提交的最终 assistant 消息；工具消息不补答案 |
| CLI | 该进程声明的最终 stdout 区段或输出文件；进度日志、stderr 单独留作审计 |
| API/结构化输出 | 响应中预先选定的字段及原生类型；JSON 可以直接是正式答案，不必改写成页面 |
| 报告工件 | 与本次 run 绑定的最终文件/版本；检查内容完成，不能只凭存在同名旧文件 |
| 流式或持续更新 | 预先约定的 terminal 提交或检查时刻；若评价多时点变化，逐时点绑定可见证据与评分 |

选择规则在看见分数前固定，并以实际消费者/产品合同为依据；不能看到答案后扩大字段补分。
必要的格式转换采用确定性方法，保留源与转换后的内容/hash；不让另一个 LLM 润色补充答卷。
若任务本身评价结构化行动或过程，则预先将这些声明为评分对象，不能暗中从轨迹给文本补分。
尚未终结、产物缺失或解析不合法分别记录，不挑某次中间消息作为“最好答案”。
区分提取器未接通/失效与 Agent 没有按合同提交：前者是接入或基础设施失败；
后者在已验收的接入下按预声明的任务完成规则记失败，不能豁免。

## 最小接入验收

先做不调用模型的接口测试：代表性正常查询、成功零行、部分覆盖、越界/不支持、
分页或原生桶边界，以及私有参考与线上数据不可达。
至少检查一个会影响判断的实际参数往返，而非只检查文件能打开。

再在授权范围运行实际入口，核对触发、请求、版本、最终产物与评分输入。
若仅有合成示例或模拟入口，只能报告合同演练；既没有业务模型运行也没有真实适配层时，
不要称生产 E2E 通过。未接入时仍可交付证据与接入计划，明确还缺哪一步。
